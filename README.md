* Skill-gap identification

A workflow-driven platform designed around the complete job-search pipeline:

```text
Resume
   ↓
Resume Parsing
   ↓
Candidate Profile
   ↓
Job Discovery
   ↓
Job Matching
   ↓
LLM Analysis
   ↓
Application Workflow
   ↓
Automated Email Digest
```

**Architecture focus:**

`React` → `FastAPI` → `n8n` → `LLM APIs` → `MongoDB` → `Job APIs`

The goal is not just to build an AI chatbot, but to understand how **LLMs can participate in real software workflows**.
